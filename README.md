# Cloud-Native Critical Event Management System

A cloud-native critical event management and automated escalation system designed to receive business-critical operational events, process them asynchronously, apply escalation rules, and notify appropriate stakeholders through email and SMS.

## Planned Technology Stack

- AWS
- Amazon EC2
- Application Load Balancer
- Amazon SQS
- Amazon RDS PostgreSQL
- Amazon SES
- Amazon S3
- Python
- FastAPI
- Docker
- PostgreSQL
- Twilio SMS
